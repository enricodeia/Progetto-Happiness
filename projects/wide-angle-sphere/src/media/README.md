# the player's audio

Drop Christopher's narration in here — `.mp3` / `.m4a` / `.wav` / `.ogg` /
`.aac`, one file (the first in filename order is the one that plays). The
player bottom-left picks it up on the next reload: the play button comes
alive and the label switches from "Audio coming soon" to
`CONFIG.player.label`.

While this folder is empty the control is fully built but disabled, and says
so — nothing plays that isn't his.
