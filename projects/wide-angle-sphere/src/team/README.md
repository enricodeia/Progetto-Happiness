# the team grid's own photos

Drop any `.webp` / `.jpg` / `.png` / `.avif` in here, one per person, in the
SAME ORDER as `src/data/team.js` — a numeric prefix (`01-…`, `02-…`) is the
simplest way to pin that order. Square crops read cleanest; the card is a
rounded square.

While a slot has no photo of its own, that card falls back to a plain
initials avatar (the person's own initials, over a flat tint) rather than
someone else's face — these are real, named people, not stock photography,
so there is nothing sensible to fall back to.
