# ring A — ordinary people

The inner ring of V2's act, the one that arrives on "On a platform guided by
people". These are **not** the teacher portraits: they are ordinary people, the
practice photographs from the V2 frames.

Drop any `.webp` / `.jpg` / `.png` / `.avif` in here. They are used in filename
order, so a numeric prefix (`01-…`, `02-…`) says where each one sits on the
orbit. Square crops read cleanest — the card is square by default
(`v2.rings.a.aspect: 1`) and the shader cover-fits whatever it is given.

While this folder is empty the ring falls back to `src/ring-media/`, then
`src/cards/`, then the teacher portraits, so the piece is never blank.
