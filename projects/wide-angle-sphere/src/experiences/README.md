# ring B — the experiences

The outer ring, the one that arrives on the second step and turns the other way.
These are the **experiences / techniques** — the practice images.

Drop any `.webp` / `.jpg` / `.png` / `.avif` in here, used in filename order.
Square crops read cleanest.

While this folder is empty the ring falls back to `src/ring-media/`, then
`src/values/`, then the teacher portraits.
