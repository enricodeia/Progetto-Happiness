# the ground's mask

`v2.ground.video` takes a path in here (e.g. `/video/ripple.webm`) and that
clip's **luminance becomes the mask** the ground opens through — white opens,
black stays paper — at the same `scale` and about the same centre as the
procedural FBM it replaces.

Until a file is named the FBM mask stands in, so the beat works either way.
Nothing else changes: the colours, the wander and the softness are all still the
panel's.
