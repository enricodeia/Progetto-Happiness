Features

Authentication

Email + Password Done
Sign up, sign in, password reset via Supabase Auth
Google OAuth Done
One-tap Google sign-in with redirect handling
LinkedIn OAuth Done
Professional sign-in via LinkedIn OIDC
Session Persistence Done
Auto-login on return, skip splash for returning users

Onboarding

12-Step Profile Setup Done
Name, DOB, role, company, location, skills, looking for, availability, photo, showcase, prompts, bio
Form Validation Done
Required field checks with specific error messages per step
Photo Upload Done
Profile picture + up to 6 project photos via Supabase Storage
Onboarding Slides Done
3 intro slides with animated mockups for new users

Discover

Swipe Cards Done
Drag-to-swipe with LIKE/NOPE indicators, photo navigation, scrollable profile content
3D Globe Mode Done
WebGL rotating carousel of profiles via ogl
Match Detection Done
Mutual like triggers match overlay with message CTA
Smart Matching Done
Profiles scored by role, industry, location, completeness. Sorted by compatibility.
Pagination Done
20 profiles per page, auto-prefetch when 3 cards from end
Bookmark/Save Done
Save profiles for later. Toggle on/off from card footer.
Daily Swipe Limit Done
25/day for free users, unlimited for Pro. Counter in header.

Chat

Realtime Messaging Done
Supabase realtime subscription for instant message delivery
Conversation List Done
Shows all matches with latest message preview, unread badges
Read Receipts Done
Messages marked as read when conversation is opened
Optimistic Send Done
Messages appear instantly before server confirmation

Profile

Edit Profile Done
Inline editing for name, role, company, location, bio, skills, photos
Preferences Done
Distance slider, remote toggle, role type filters, industry filters
Looking For Done
Multi-select: collaborator, hire, mentor, co-founder, freelance, agency
Settings Done
Email, password, push/email toggles, profile visibility, logout
Completion Ring Done
SVG ring showing profile completion percentage

Monetization

Pro Paywall Done
Feature list, pricing, animated checkout loading state
Stripe Checkout Done
Edge function creates Stripe session, redirects to checkout
Webhook Handler Done
Handles subscription events, updates is_pro flag
Checkout Return Done
Success toast + Pro activation on return from Stripe

Security

Row Level Security Done
All tables (profiles, swipes, messages, saves) have RLS policies
Secure Views Done
public_profiles hides Stripe data. get_my_matches() scoped to caller.
Scoped Storage Done
Avatar uploads restricted to user's own folder

Infrastructure

Vercel Deploy Done
pairo.vercel.app, auto-deploy from CLI
Vitest Suite Done
11 tests covering constants and profile normalization
Terms & Privacy Done
Static pages linked from signup form

Not Yet Built

Saves, Connections, Views counters (currently hardcoded to 0)

UI exists in settings but not connected
Push Notifications Planned
Toggle exists but no FCM/APNs integration

No confirmation flow UI
